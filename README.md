# BFG 电量校准（网页版）

纯前端的电量校准工具：浏览器用 Web Bluetooth 直接连车，读写仪表里的电压 / 容量档位。
单个 HTML 文件，没有后端、没有依赖、不发任何网络请求。

## 它是做什么的

九号部分车型的电量显示由 BFG 计量板 + 仪表给出。仪表里存着一个**档位字节**，决定它按多少伏、多大容量去算 SOC 和续航。
换过电池、改过电压之后，档位还是旧的，表显电量和续航就会算错。
这个工具的作用就是把档位改成和车上实际电池一致，让表显回到正确值。

## 功能

**连接**
- 按 Nordic UART 服务 `6e400001-…` 过滤扫描，列表里只出现车
- 自动分片写入，默认 20 字节，兼容 Write / Write Without Response

**认证**
- PRE_COMM：用 16 字节密码派生掩码，取回 `authParam` 和车辆 SN
- AUTH：用 SN 认证，建立 Encryption2 会话（AES-CTR + 4 字节 CBC-MAC，收发计数器自动对齐）

**读取**（逐项显示，可对比）

| 项目 | 组 / 寄存器 | 说明 |
|---|---|---|
| Profile | `0x10 / 0x00` | 当前档位字节 |
| Profile SOC | `0x10 / 0x02` | 百分比 |
| capacity_core | `0x10 / 0x1C` | 电池容量（LE16） |
| 仪表版本 | `0x01 / 0x1A` | 写档位前的版本核对 |
| 能量参数 | `0x01 / 0x1E` | |
| BFG 版本 | `0x01 / 0x3D` | |
| 剩余容量 | `0x01 / 0x44` | |
| 电压配置 | `0x01 / 0x92` | 低半字节 = 电压码 |
| 电压 | `0x01 / 0xB1` | |
| 仪表 SOC | `0x01 / 0xB5` | |

**写入**
- 写 Profile：`(容量档 << 4) | 电压码`，电压码 1 = 72V、2 = 60V、3 = 48V
- 写电压配置 `0x92`：只替换低半字节，高半字节保留原值
- 两者写入成功后都会自动回读，并把回读值和目标值一起打到日志里

**配对**
- 生成 32 字节新密钥并 SET_PWD 写入车端（车端需按键确认，之后原密码失效）

**日志**
- 每一帧收发的十六进制、应答内容、状态都实时打印，可一键复制

## 支持范围

- 车辆：广播里带 NUS 服务（`6e400001-…`）的九号车型，BFG 计量板 + 仪表这套组合
- 浏览器：Chrome、Edge（桌面和安卓都行）；Safari 和 iOS 上的浏览器没有 Web Bluetooth
- 环境：必须 `https://` 或 `http://localhost`，`file://` 打不开蓝牙

## 自己部署

页面就是一个静态文件，放哪都行，前提是能通过 https 访问。

**方式一：自己的服务器 / 宝塔**

把 `web/index.html` 传到站点根目录（或任意子目录），确认 https 能打开即可。

**方式二：GitHub Pages**

Fork 本仓库 → Settings → Pages → Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/web` → 保存。
几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

**方式三：本地跑**

```bash
python -m http.server 8000
# 打开 http://localhost:8000/web/index.html
```

## 怎么用

1. 用 Chrome / Edge 打开你部署好的地址（iPhone 需要用支持 Web Bluetooth 的第三方浏览器）
2. 点「扫描并连接」，选中你的车
3. 密码：没配对过就留空（用设备名当出厂密码）；配对过就填 16 字节密钥（32 位 hex）
4. 点「1. PRE_COMM」，拿到 SN 和 authParam
5. 点「2. AUTH」，进入加密会话
6. 点「3. 读全部寄存器」，把 `profile`、`capacity_core 0x1C`、`0x92` 的原始值记下来
7. 选容量档 + 电压档 →「写 Profile」，页面会自动回读
8. 要改 `0x92` 的话：先读一次，再点「写 DIS 配置」

## 注意

- 写之前先把原始值抄下来，写错了用同样的方法写回去
- 写 `0x92` 只改低半字节（电压），高半字节必须保留，否则表显会更乱
- 写入会改变车辆电量显示口径，请只在自己车上用
- 表显不对先断开重连、仪表断电重启再看
